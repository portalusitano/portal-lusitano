# 🎨 Como Criar Capa Profissional para o Ebook

Este guia ensina-te a criar uma capa de qualidade editorial para o ebook **"Introdução ao Cavalo Lusitano"**.

---

## 📐 Especificações Técnicas

### Dimensões

- **Tamanho**: A4 (210 x 297 mm)
- **Resolução**: 300 DPI (mínimo)
- **Orientação**: Vertical (Portrait)
- **Sangria**: 3mm (se for imprimir)

### Cores Portal Lusitano

```
Gold Principal:   #C5A059 (RGB: 197, 160, 89)
Gold Escuro:      #8B6914 (RGB: 139, 105, 20)
Preto:            #050505 (RGB: 5, 5, 5)
Branco:           #FFFFFF
Cinza Claro:      #F5F5F5
```

## 🎯 MÉTODO 1: Canva (Mais Fácil - 30 minutos)

### Passo 1: Setup Inicial

1. Ir a https://www.canva.com
2. Criar conta gratuita (ou fazer login)
3. Clicar em "**Create a design**"
4. Selecionar "**Custom size**": 2480 x 3508 pixels (A4 em 300 DPI)

### Passo 2: Escolher Template Base

1. Na barra lateral esquerda, clicar em "**Templates**"
2. Pesquisar: "**book cover elegant**" ou "**ebook cover minimalist**"
3. Filtrar por:
   - Cor: Gold/Dourado
   - Estilo: Elegante, Minimalista
   - Grátis (se não tiveres Canva Pro)

**Templates Recomendados** (pesquisar estes nomes):

- "Elegant Gold Book Cover"
- "Luxury Minimalist Ebook"
- "Classic Literature Cover"

### Passo 3: Customizar Design

#### ELEMENTO 1: Background

- **Opção A**: Gradiente Gold

  ```
  Tipo: Linear
  Cor 1: #C5A059 (topo)
  Cor 2: #8B6914 (baixo)
  Ângulo: 135°
  ```

- **Opção B**: Imagem de Cavalo Lusitano
  - Pesquisar em Canva: "white horse elegant"
  - Ou usar Unsplash/Pexels (gratuito):
    - https://unsplash.com/s/photos/white-horse
    - https://www.pexels.com/search/white%20horse/
  - Aplicar overlay escuro (opacidade 40-60%)

#### ELEMENTO 2: Título Principal

```
Texto: "INTRODUÇÃO AO CAVALO LUSITANO"

Fonte Recomendada (escolher 1):
- Playfair Display (Serif, elegante)
- Cormorant Garamond (Serif, clássico)
- Cinzel (Serif, imperial)
- Bodoni* (Serif, editorial)

Tamanho: 70-90pt
Cor: #FFFFFF (se background escuro) ou #050505 (se background claro)
Weight: Bold (700)
Espaçamento: 5-10%
Alinhamento: Centro
Maiúsculas: SIM
```

#### ELEMENTO 3: Subtítulo

```
Texto: "O Guia Essencial Para Iniciantes"

Fonte: Mesma do título mas Italic
OU
Fonte: Lato, Open Sans (Sans-serif para contraste)

Tamanho: 24-32pt
Cor: #C5A059 ou #FFFFFF
Weight: Light (300) ou Regular (400)
Alinhamento: Centro
```

#### ELEMENTO 4: Topo (Eyebrow)

```
Texto: "PORTAL LUSITANO PRO"

Fonte: Montserrat, Raleway (Sans-serif)
Tamanho: 16-20pt
Cor: #C5A059
Weight: SemiBold (600)
Maiúsculas: SIM
Espaçamento letras: 20-30%
Posição: Topo central, ~50mm do topo
```

#### ELEMENTO 5: Ornamentos

- **Linhas Decorativas**:
  - Acima e abaixo do título
  - Cor: #C5A059
  - Espessura: 2-3px
  - Comprimento: 150-200px

- **Ícones** (opcional):
  - Pequena silhueta de cavalo
  - Ferradura
  - Coroa (referência "Lusitano = realeza")

#### ELEMENTO 6: Rodapé

```
Texto: "30 PÁGINAS • DOWNLOAD GRATUITO"

Fonte: Open Sans, Lato
Tamanho: 14-16pt
Cor: #FFFFFF ou #999999
Posição: Base, ~30mm do fundo
Alinhamento: Centro
```

### Passo 4: Layout Final Recomendado

```
┌─────────────────────────────────┐
│                                 │ ← 50mm
│      PORTAL LUSITANO PRO        │ ← Eyebrow
│                                 │

│                                 │
│        INTRODUÇÃO AO            │ ← Título (grande)
│      CAVALO LUSITANO            │
│                                 │
│     ━━━━━━━━━━━━━━━━━━━━━      │ ← Ornamento
│                                 │
│   O Guia Essencial Para         │ ← Subtítulo
│        Iniciantes               │
│                                 │
│    [Imagem cavalo ou            │ ← Imagem (opcional)
│     gradiente gold]             │
│                                 │
│                                 │
│  30 PÁGINAS • DOWNLOAD GRATUITO │ ← Footer
│                                 │ ← 30mm
└─────────────────────────────────┘
```

### Passo 5: Exportar

1. Clicar em "**Share**" (topo direita)
2. Selecionar "**Download**"
3. Formato: **PDF - Print** (melhor qualidade)
4. Qualidade: **Máxima** (300 DPI)
5. Guardar como: `capa-ebook-lusitano.pdf`

## 🎨 MÉTODO 2: Figma (Mais Controlo - 45 minutos)

### Passo 1: Setup

1. Ir a https://www.figma.com
2. Criar conta gratuita
3. New File → New Design File
4. Press **F** (Frame tool)
5. Criar frame: 2480 x 3508 px

### Passo 2: Grid e Guides

```
Margins: 100px (todos os lados)
Columns: 12
Gutter: 20px
Rows: 24
Gutter: 20px
```

### Passo 3: Elementos (criar layers)

#### Background

```
Rectangle: 2480 x 3508
Fill: Linear Gradient
  Stop 1: #C5A059 (0%)
  Stop 2: #8B6914 (100%)
  Angle: 135°
```

#### Título

```
Text: "INTRODUÇÃO AO\nCAVALO LUSITANO"
Font: Playfair Display Bold
Size: 90px
Line Height: 100px
Letter Spacing: 5%
Color: #FFFFFF
Align: Center
Position: Y = 800px (centrado verticalmente)
```

#### Ornamentos

- Use **Line Tool** (L)
- Stroke: 3px, #FFFFFF
- Comprimento: 400px
- Posicionar acima/abaixo título

### Passo 4: Exportar

1. Selecionar frame
2. **Export** (painel direita)
3. Formato: **PDF**
4. Escala: **1x**
5. Download

## 📷 MÉTODO 3: Photoshop (Máxima Qualidade - 60 minutos)

### Passo 1: Novo Documento

```
Largura: 210 mm
Altura: 297 mm
Resolução: 300 DPI
Modo cor: CMYK (para impressão) ou RGB (para digital)
Background: Branco
```

### Passo 2: Criar Background

1. **Layer → New Fill Layer → Gradient**
2. Configurar:
   ```
   Estilo: Linear
   Ângulo: 135°
   Cor 1: #C5A059 (CMYK: 20, 30, 70, 0)
   Cor 2: #8B6914 (CMYK: 30, 45, 85, 20)
   ```

### Passo 3: Adicionar Imagem de Cavalo (Opcional)

1. Descarregar imagem alta resolução (min 2000px):
   - Unsplash: https://unsplash.com/s/photos/lusitano-horse
   - Pexels: https://www.pexels.com/search/white%20horse/

2. Importar: **File → Place Embedded**

3. Ajustar:
   - Opacidade: 30-40%
   - Blend Mode: Overlay ou Soft Light
   - Mask: Gradient mask (fade para baixo)

### Passo 4: Adicionar Texto

#### Eyebrow

```
Ferramenta Texto (T)
Texto: "PORTAL LUSITANO PRO"
Fonte: Montserrat SemiBold
Tamanho: 24pt
Tracking: 200
Cor: #FFFFFF
```

#### Título Principal

```
Texto: "INTRODUÇÃO AO CAVALO LUSITANO"
Fonte: Playfair Display Bold
Tamanho: 110pt
Leading: 120pt
Tracking: 50
Cor: #FFFFFF
All Caps: Yes

Efeitos:
- Drop Shadow (subtle):
  Opacidade: 30%
  Distância: 3px
  Blur: 8px
```

### Passo 5: Ornamentos

1. **Line Tool** (U)
2. Desenhar linhas decorativas
3. Adicionar **Layer Style → Stroke** (2-3px, #FFFFFF)

### Passo 6: Exportar

```
File → Export → Export As...
Formato: PDF
Qualidade: Maximum
Preservar edição: Desligado
Guardar
```

## ✅ Checklist de Qualidade

Antes de finalizar a capa:

- [ ] Título é legível mesmo em thumbnail pequeno (100x100px)?
- [ ] Cores estão corretas (#C5A059, #8B6914)?
- [ ] Resolução é 300 DPI?
- [ ] Texto não tem erros ortográficos?
- [ ] Margens respeitadas (min 10mm das bordas)?
- [ ] Contraste suficiente (texto vs background)?
- [ ] Imagem de cavalo (se usada) é de alta qualidade?
- [ ] PDF exportado sem compressão excessiva?
- [ ] Tamanho ficheiro razoável (< 5 MB)?

## 📤 Integração com o Ebook

### Depois de criar a capa:

1. **Guardar em**: `public/images/ebook-capa.jpg` (para website)
2. **Usar na landing page** (/ebook-gratis):

   ```jsx
   <Image src="/images/ebook-capa.jpg" alt="Capa do Ebook" width={400} height={565} />
   ```

3. **Adicionar ao PDF**:
   - Se usaste o script premium, a capa já é gerada automaticamente
   - Ou importar manualmente no inicio do PDF

   - **Capa completa**: Para PDF
